# Server Setup

<Tabs>
  <TabItem value="docker" label="Docker" default>

## Step 1: Create directories

```bash
mkdir -p cloud-dev-stack/{config,projects,init.d,shared}
cd cloud-dev-stack
```

## Step 2: Download the files

```bash
# Container init script (desktop)
curl -fsSL https://raw.githubusercontent.com/Piero24/Cloud-Dev-Desktop/main/init.sh \
  -o init.d/99-ssh.sh
chmod +x init.d/99-ssh.sh

# Container init script (vscode)
curl -fsSL https://raw.githubusercontent.com/Piero24/Cloud-Dev-Desktop/main/init.d/99-vscode-env.sh \
  -o init.d/99-vscode-env.sh
chmod +x init.d/99-vscode-env.sh

# Plain Docker Compose file
curl -fsSL https://raw.githubusercontent.com/Piero24/Cloud-Dev-Desktop/main/compose.yaml \
  -o compose.yaml
```

## Step 3: Edit the values

```bash
nano compose.yaml
```

Replace in the **desktop** service:
- `CHANGE_ME_USERNAME` — your system username. Used for SSH and file ownership
- `CHANGE_ME_WEB_PASSWORD` — login password for KasmVNC (desktop) and code-server
- `CHANGE_ME_SUDO_PASSWORD` — sudo password, also used for SSH login
- `CHANGE_ME_ANTHROPIC_KEY` — your [Anthropic API key](https://console.anthropic.com)
- `CHANGE_ME_GIT_NAME` / `CHANGE_ME_GIT_EMAIL` — your Git identity
- `CHANGE_ME_GITHUB_TOKEN` — GitHub [fine-grained PAT](https://github.com/settings/tokens?type=beta)
- `CUSTOM_RES_W` / `CUSTOM_RES_H` — desktop resolution (default 1920×1080)
- `TZ` — your timezone

:::tip[Both containers share the same home]

Desktop and vscode mount the same `./config` volume as `/config` — they share shell config, git identity, nvm, Node, Claude Code, and all installed packages. Install something in one, it's available in the other.

:::

## Step 4: Create the NPM network

If you already have Nginx Proxy Manager running with a custom network, skip this:

```bash
docker network create npm-network
```

## Step 5: Start the stack

```bash
docker compose up -d
docker ps | grep dev-
```

You should see three containers: `dev-desktop`, `dev-vscode`, and `dev-beszel-agent`.

## Step 6: Test direct access

| Test | URL / Command |
|------|---------------|
| Web desktop | `http://<server-ip>:3000` — KasmVNC login (user: your `CUSTOM_USER`, pass: `PASSWORD`) |
| Web VS Code | `http://<server-ip>:9090` — code-server login (pass: `PASSWORD`) |
| SSH | `ssh -p 3434 <CUSTOM_USER>@<server-ip>` — login with `SUDO_PASSWORD` |

If all three work, the stack is running correctly.

## Post-Setup

These steps are not required for the stack to run — they wire up external access, API keys, and monitoring.

### API keys and Git

All API and Git configuration is set through environment variables in the compose file. See the full reference:

👉 **[Environment Variables Reference](./env-vars)**

Only `ANTHROPIC_AUTH_TOKEN` is mandatory. Everything else has sensible defaults.

### Wire up Nginx Proxy Manager

In your existing NPM dashboard (port 81), add two Proxy Hosts:

| Domain | Forward Hostname | Forward Port | WebSocket | SSL |
|--------|-----------------|--------------|-----------|-----|
| `desktop.yourdomain.com` | `dev-desktop` | `3000` | **ON** | Let's Encrypt |
| `code.yourdomain.com` | `dev-vscode` | `8443` | **ON** | Let's Encrypt |

:::warning[WebSocket support is mandatory]

Both KasmVNC (desktop) and code-server rely on WebSocket connections. Without the **WebSocket Support** toggle enabled in NPM, you'll see:
- Desktop: login page loads, then "WebSocket disconnected. Attempting to reconnect..." loops forever
- Code-server: connection resets or "This application requires a secure connection" errors

:::

No Advanced tab config needed — just SSL + WebSocket. Each app has its own password (the `PASSWORD` you set earlier).

:::tip

`dev-desktop` and `dev-vscode` are Docker container names. Because they share `npm-network` with NPM, Docker's internal DNS resolves these names automatically.

:::

### Beszel agent (optional)

Sends CPU, RAM, disk, and Docker metrics to your existing [Beszel](https://beszel.dev) hub.

**Get the agent key:** In your Beszel hub UI, click **Add system** and copy the SSH public key. Paste it as `CHANGE_ME_BESZEL_KEY` in the compose file.

**Verify the listen port:** The agent listens on port `45002` (`LISTEN` env var). Make sure your Beszel hub is configured to connect to this server on port 45002.
